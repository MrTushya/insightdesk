# InsightDesk

InsightDesk is a full-stack complaint management system that allows users to submit and track complaints through a web-based dashboard.

## Features

- Complaint submission
- Complaint status tracking
- Dashboard with complaint statistics
- User authentication
- REST API integration
- SQLite database
- React-based frontend
- Node.js and Express.js backend
- Responsive web interface

## Tech Stack

### Frontend
- React.js
- JavaScript
- HTML
- CSS
- Vite

### Backend
- Node.js
- Express.js
- REST APIs

### Database
- SQLite
